**The World in One Day** — a flat editorial poster that sums up the world news of Thursday 19 November 2026 in a single 1024×1024 image. The hero panel covers the worldwide launch of GTA VI after a 13-year wait; the panels below cover the first Xi–Trump–Putin trilateral summit in Shenzhen and its peace declaration, the ICJ ruling that Myanmar is guilty of genocide against the Rohingya (the first state ever held responsible), Anthropic's record-breaking $81.3B Nasdaq IPO, and the unrest in Bangladesh — with a ticker for the Gaza peace plan's shortfalls and the EU's proposed €45B loan for Ukraine. The poster is drawn programmatically (Python/PIL) so every label stays crisp, and `main.ts` copies it to `/output/entry.png`.

## Run it

```sh
node main.ts
```
